## Featured

| Project | What it is |
|---|---|
| **[AI Studio Hub](https://github.com/jrlabanza/ai-studio-hub)** | Five local AI studios sharing one 8 GB graphics card: Image (Qwen-Image-2.1, Iris-3B Turbo), Voice (Qwen3-TTS, Chatterbox, Fish Audio Drama-3), Video (LTX-2.5, MiniMax H3 - storyboards, extend, a built-in editor), Music (YuE2) and Forge. Each runs on demand in its own Docker container; the hub hands the GPU between them. Python · FastAPI · Docker · ComfyUI |
| **[Music Studio](https://github.com/jrlabanza/music-generator)** | YuE2 songs from lyrics and a style, with an editable score, on an 8 or 16 GB card. |
| **[BRACKET.GG](https://github.com/jrlabanza/bracket.gg)** | A tournament platform in one HTML file: seeding, double elimination, live set reporting, standings. |
| **[Online Trivia](https://github.com/jrlabanza/office-trivia-web-game)** | Kahoot-style multiplayer trivia for your LAN, with a built-in quiz editor. |
| **[Prompt Enhancer](https://github.com/jrlabanza/sd-prompt-enhancer)** | Guided prompt builder and reference-image tagger for Forge. |
| **[LoRA Trainer](https://github.com/jrlabanza/sd-lora-trainer)** | From a handful of images to a trained SDXL LoRA, in one tab. |
